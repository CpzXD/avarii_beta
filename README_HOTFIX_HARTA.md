# Hotfix interfață și hărți

Versiunea folosește Leaflet local, din `public/vendor/leaflet`, astfel încât hărțile și JavaScript-ul principal nu mai depind de încărcarea bibliotecii de pe un CDN extern.

## Actualizare

1. Copiază toate fișierele peste repository-ul local.
2. Commit: `Fix interfață și hartă`.
3. Push origin.
4. Așteaptă `Deploy live` în Render.
5. Deschide aplicația o dată în browser și fă refresh. Dacă este instalată ca PWA și păstrează versiunea veche, închide-o complet și redeschide linkul în browser.
