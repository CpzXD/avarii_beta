# Avarii iluminat - demo PWA

Demo Node/Express pentru raportarea avariilor de iluminat public.

## Pornire locală

```bash
npm install
npm start
```

Utilizator:
- http://localhost:3000/harta.html

Admin:
- http://localhost:3000/admin-login.html

## Aplicație pe telefon

Proiectul este pregătit ca PWA:
- manifest pentru instalare pe telefon;
- iconițe;
- service worker;
- buton de instalare în tabul Cont.

Pentru GPS și instalare corectă pe telefon, rulează aplicația prin HTTPS.
Pentru test rapid poți folosi VS Code Port Forwarding / Dev Tunnels.
Pentru demo public poți folosi un hosting Node/Express, de exemplu Render.
